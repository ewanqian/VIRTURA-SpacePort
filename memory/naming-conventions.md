# Naming Conventions

## General
- use lowercase where possible
- use hyphen-separated filenames
- names should describe function, not vague mood
- avoid duplicate words unless necessary

## Preferred examples
- internal-full-record.md
- public-summary.md
- workflow-retrospective.md
- project-entry.md
- stage-note.md

## Avoid
- new.md
- temp.md
- final-final.md
- test2.md
- random-note.md
