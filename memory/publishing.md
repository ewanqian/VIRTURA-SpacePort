# Publishing

## Goal
Public-facing text should function as an entry point, not as a dump of internal process.

## Rules
- Start with the simplest useful sentence.
- Make clear what this page is.
- Give the reader a path to continue.
- Link deeper material rather than overloading the entry page.
- Preserve tone, but prioritize clarity.

## Public page minimum structure
- title
- one-sentence description
- why it exists
- key points
- where to go next

## Avoid
- too much internal shorthand
- over-explaining theory before orientation
- posting raw notes without cleaning
