# Agent Mistakes

## Common failure modes
- Creates new files when it should update an existing structured file
- Summarizes without preserving the main judgment
- Produces readable text but loses repository logic
- Treats archive as storage, not as future usability
- Mixes public and internal writing layers
- Fails to add links or next-step paths
- Leaves output disconnected from existing station structure

## Prevention
- Always read nearby files first
- Prefer updating existing entry pages
- Check whether the output is internal or public
- Preserve structure, not just prose
- Add links whenever discoverability matters
