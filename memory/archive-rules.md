# Archive Rules

## Goal
Archiving is not file dumping. Archiving means preserving a usable future state.

## Rules
- Archive with context, not only files.
- Every archive item should have a readable title.
- Every important archive should explain:
  - what it is
  - why it matters
  - related links
  - whether it is internal or public
- If a file is hard to understand alone, add a markdown companion note.
- Avoid unnamed version piles like final2 / final3 / final-final.

## Good archive test
A stored item passes only if:
- it can be found later
- it can be understood later
- another person can pick it up
- it can connect to a future update
