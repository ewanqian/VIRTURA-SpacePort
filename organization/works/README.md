## Public Graph / 对象关系规则

这里是 `archive_view`，负责保留版本、资料、公开证据和 source-of-truth。不要在这里重复维护个人简介、团队首页口径或文章评论；那些分别回到 `portfolio`、`VIRTURA-Collective` 和 `VIRTURA-Newsroom`。

统一关系：

```text
portfolio = personal_view + personal fact layer
Collective = team_view
SpacePort = archive_view / version evidence
Newsroom = publication_view
```
