# SYSTEM × ERSHA — Point Cloud Factory / 二砂建筑空间扫描

**2026 / Spatial Capture / Moving Image / VIRTURA**

围绕郑州中国第二砂轮厂建筑空间展开的影像制作合作。空间采集记录厂区立面、楼层、纵深与工业结构；清理和重组后的点云模型被用于镜头预演与特效影像，使建筑可以被重新观看、剖开和组织。

**钱誉文 / Ewan Qian** 在与 SYSTEM 相关的影像项目中承担厂区点云扫描、三维重建与视觉特效工作。合作纪录片的正式名称、完整摄制署名及原始素材可再利用范围仍以正式资料为准。

## 下一阶段：独立空间影像

Ewan 计划基于现有数字空间重新剪辑原创影像，采用新的配乐和镜头编排重新演绎厂房。该方向是**未来个人剪辑版本**，不等于此前合作影片已发布的新版本。公开前须核对数据、人物、画面及音乐版权。

## English

*SYSTEM × ERSHA* is an architectural capture and moving-image collaboration around the China Second Grinding Wheel Factory in Zhengzhou. Ewan Qian's work includes point-cloud scanning, 3D reconstruction and visual effects. A separately edited and newly scored spatial interpretation is proposed but has not been released.
