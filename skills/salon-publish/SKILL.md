# Skill: Salon Publish

## Description
Use this skill when a VIRTURA Space Salon session needs to be turned into public-facing and internal repository updates.

## Use when
- a salon has ended
- there is a transcript or notes
- the salon page needs updating
- a public summary should be published

## Inputs
- salon transcript or notes
- current salon folder
- station index page
- public summary requirement
- related links

## Steps
1. Read the transcript and identify the core thread.
2. Extract 3 main judgments only.
3. Separate:
   - internal full record
   - public-readable summary
   - key takeaway text
4. Update the current salon folder.
5. Update the salon index if needed.
6. Add links to related research or station pages.
7. Create a short external-facing summary if needed.
8. Record reusable workflow lessons in memory if new.

## Outputs
- updated internal record
- updated public summary
- index link update
- optional social summary

## Checklist
- Is the salon page readable for first-time visitors?
- Are internal and public layers separated?
- Are the core 3 judgments clear?
- Is the GitHub path included when needed?
