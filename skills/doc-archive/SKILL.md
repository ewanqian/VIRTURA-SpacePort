# Skill: Document Archive

## Description
Use this skill when raw text, chats, transcripts, notes, or records need to be converted into structured repository material.

## Use when
- a meeting ended
- a salon ended
- a long discussion contains reusable judgments
- raw notes need archiving
- a chat should become repo knowledge

## Inputs
- raw text or transcript
- target folder or station
- whether output is internal or public
- related links if available

## Steps
1. Read the material fully.
2. Identify the main topic.
3. Extract 3-5 key judgments.
4. Separate summary from raw detail.
5. Create or update the appropriate markdown file.
6. Add title, context, and next-step hints.
7. Link related pages if discoverability matters.
8. If a reusable pattern appears, update memory files.

## Outputs
- structured markdown note
- summary if needed
- archive-ready page
- memory update if applicable

## Checklist
- Is this in the correct folder?
- Is the title readable?
- Is the context clear?
- Is the page internal or public?
- Can someone else understand it later?
