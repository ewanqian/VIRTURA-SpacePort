# VIRTURA SPACEPORT — CANONICAL BIBLES

> Updated: 2026-09-06

This directory contains the current foundational specifications for the 2026 Spaceport rebuild.

## Canonical documents

1. [WORLD BIBLE v1.1](./VIRTURA-SPACEPORT-WORLD-BIBLE-v1.1.md)  
   Defines what the world is, its Station network, first-generation facilities, routes, historical continuity, and spatial culture.

2. [ARCHITECTURE BIBLE v1.0](./VIRTURA-SPACEPORT-ARCHITECTURE-BIBLE-v1.0.md)  
   Defines scale, docking, architecture, material, lighting, human scale, interaction, XR comfort, and architectural QA.

3. [PRODUCTION BIBLE v1.0](./VIRTURA-SPACEPORT-PRODUCTION-BIBLE-v1.0.md)  
   Defines runtime, repository roles, asset pipeline, AI/Harness governance, performance, release, archive, and cost control.

4. [STATION BIBLE v1.0](./VIRTURA-SPACEPORT-STATION-BIBLE-v1.0.md)  
   Defines A00–A07 and F00–F07 as a canonical facility catalogue: roles, users, spatial programs, relationships, capabilities, and build priorities.

## Reading order

For new collaborators or AI agents:

```
WORLD BIBLE
→ ARCHITECTURE BIBLE
→ PRODUCTION BIBLE
→ STATION BIBLE
→ station manifest
→ station Build Card
→ source assets / runtime
```

These documents are intended to reduce reinvention and keep the Spaceport coherent as it grows.
