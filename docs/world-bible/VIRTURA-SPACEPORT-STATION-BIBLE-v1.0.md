# VIRTURA SPACEPORT — STATION BIBLE v1.0

> Status: CANONICAL FACILITY CATALOGUE  
> Date: 2026-09-06  
> Scope: A00–A07 public/cultural Stations and F00–F07 infrastructure Stations  
> Reads with: World Bible v1.1 / Architecture Bible v1.0 / Production Bible v1.0

## 0. Purpose

This document defines what each first-generation Spaceport facility is for.

It does not replace individual Build Cards.

Its role is to make sure every Station has:
- a clear reason to exist;
- a defined primary user;
- a spatial program;
- a relationship to the rest of the Spaceport;
- an architectural direction;
- a technical capability profile;
- a construction priority;
- a boundary against duplication.

A Station should not be created because “the world needs more buildings.”

A Station exists only when it performs a durable function.

# PART I — PUBLIC / CULTURAL STATIONS

## A00 — Orbital Arrival Terminal / 轨道到达港

### Role

Public front door of the Spaceport.

A00 is the transfer point between:
- the ordinary website;
- the 3D world;
- WebXR;
- current programs;
- destination routing;
- meetings;
- live spaces;
- archives.

It is not a narrative prologue. It is real public infrastructure.

### Primary users

- first-time visitor;
- returning audience;
- artist;
- collaborator;
- client;
- researcher;
- XR visitor.

### Primary questions it must answer

Within a short visit, the user should know:
- where am I;
- what is happening now;
- what is open;
- where can I go;
- do I Browse, Walk, enter XR, or Join.

### Spatial program

Required:
- Arrival Threshold;
- Orientation Hall;
- Route Table;
- Current Program Wall;
- Public Ports;
- XR Gate;
- Waiting / Quiet Edge;
- information / concierge point;
- service corridor behind public space.

Optional later:
- meeting check-in;
- luggage / asset transfer metaphor;
- route observation deck;
- temporary installation area.

### Recommended scale

- Class: H96
- public hall: major civic interior
- large-span but human-readable
- primary clear height: approximately 9–18 m depending on zone

### Port logic

A00 should expose the clearest route logic in the entire Spaceport.

Initial public routes:
- MOVA;
- Balloon;
- Senia;
- T-House;
- Perceptual Engine Lab;
- Archive / Forum cluster.

### Architectural direction

Reference:
- contemporary airport lounge;
- ferry / cruise terminal;
- museum lobby;
- scientific campus;
- premium public infrastructure.

Avoid:
- spaceship cockpit;
- military command center;
- hologram room;
- luxury mall;
- giant empty white hall without public behavior.

### Material direction

- satin structural alloy;
- mineral / ceramic floor;
- clear and lightly diffused glass;
- warm neutral acoustic surfaces;
- dark metal accents.

### Lighting

- strong daylight logic;
- soft ambient bounce;
- low-glare night mode;
- route gates slightly brighter than waiting zones.

### Sound

- low mechanical bed;
- sparse route chime;
- distant structure / air tone;
- controlled previews from active destinations.

### Capabilities

- Web 2D: required
- Web 3D: required
- WebXR: required target
- Multiplayer: optional
- Live media: optional
- Gaussian: not required

### Current priority

P0 / first spatial infrastructure to mature.

### Success condition

A00 succeeds when a first-time visitor can understand the Spaceport without reading the World Bible.

# PART V — CREATION RULE

Before creating any new Station beyond A00–A07 / F00–F07, answer:

1. What durable function is missing?
2. Why cannot an existing Station absorb it?
3. Who is the primary user?
4. What happens there repeatedly?
5. Why does this need spatial form?
6. What Station class is appropriate?
7. Which ports and routes are required?
8. What operational infrastructure does it depend on?
9. What is the smallest meaningful first version?
10. What existing Station would become weaker if this one were created?

The last question is intentionally adversarial.

If a new Station merely steals the role of an existing one, it should not be built.
