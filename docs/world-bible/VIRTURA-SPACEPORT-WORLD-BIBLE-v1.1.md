# VIRTURA SPACEPORT — WORLD BIBLE v1.1

> Status: CANONICAL FOUNDATION  
> Date: 2026-09-06  
> Scope: world definition, spatial culture, station system, visitor logic, historical continuity

## 0. Canonical Definition

VIRTURA Spaceport is a continuously expanding online spatial-cultural campus.

It is composed of independently usable digital buildings and public facilities connected through shared infrastructure, virtual routes, archives, spatial standards, and production rules across Web and XR.

A Station is the primary unit of the world.

A Station is not merely a page, scene, or 3D asset. It must have:
- a role;
- a public address;
- a spatial identity;
- a current operational state;
- relationships to other Stations;
- an archive;
- a maintenance path.

The Spaceport is not a single monolithic map. It is a persistent network of destinations.

---

## 1. Core Question

The project does not primarily ask:

> What will the future look like?

It asks:

> If digital spaces become long-term cultural infrastructure, how should they be designed, operated, maintained, archived, and revisited?

The world is therefore grounded in ordinary but important human needs:

- viewing;
- meeting;
- performing;
- researching;
- resting;
- learning;
- archiving;
- broadcasting;
- visiting;
- returning.

The future is treated as usable public infrastructure rather than spectacle.

---

## 2. Why “Spaceport”

“Spaceport” carries two meanings.

### Port
A public system for:
- arrival;
- departure;
- transfer;
- waiting;
- orientation;
- destination;
- routes;
- access.

### Spatial
A system connecting multiple kinds of digital and physical spatial interfaces:
- ordinary web;
- desktop;
- mobile;
- browser 3D;
- Vision Pro;
- Quest;
- VRChat derivatives;
- exhibition installations;
- live broadcast;
- spatial media.

VIRTURA Spaceport is therefore a public transfer layer between spaces.

---

## 3. Continuous Present

The canonical public Spaceport does not require a fixed future year.

Its default time model is:

**Continuous Present / Near Future**

This allows the system to remain current while historical simulations retain their own dates and fiction.

## 5. Spatial Model

The Spaceport grows as a network of Stations rather than as one giant city scene.

Reference types:
- port;
- university campus;
- research district;
- world exposition;
- resort;
- island network;
- airport;
- cultural district.

Each Station may be independently loaded, visited, linked, updated, or archived.

New growth follows:

```
EXISTING STATION
→ AVAILABLE PORT
→ ROUTE
→ NEW STATION
```

The world should expand without requiring global reconstruction.

---

## 6. Hex Station Protocol

The hexagonal system is an infrastructure grammar, not a mandatory visible architectural style.

It establishes:
- six-direction docking;
- modular expansion;
- routing;
- loading boundaries;
- station adjacency;
- AI-readable planning;
- shared spatial logic.

Ports:

```
        P0
    ╱────────╲
 P5            P1
 │              │
 │    STATION   │
 │              │
 P4            P2
    ╲────────╱
        P3
```

Architecture may hide, distort, or reinterpret the hexagonal planning geometry as long as docking compatibility is preserved.

## 10. Routes

VIRTURA Routes is the navigation layer of the Spaceport.

A route simultaneously represents:
- transport in-world;
- URL routing;
- loading boundaries;
- scene preloading;
- transitions;
- destination relationships.

Example:

```
A00 ARRIVAL
→ ROUTE A00-A02
→ A02 BALLOON
```

Fast travel is canonical.

Users are never required to physically cross the entire world to reach useful content.

External destinations may later connect through the same route language.

---

## 11. Access Modes

Every major Station should support an appropriate subset of:

### Browse
Information-first web access.

### Walk
Browser-based 3D.

### XR
Immersive WebXR.

### Join
Live, social, meeting, or multiplayer access.

The spatial layer must never replace the information layer.

A user should not need to load a large 3D world to read one text, watch one video, or find one event.

## 13. Spatial Culture

The world should draw from:
- contemporary architecture;
- museums;
- research campuses;
- resorts;
- airports;
- ferry terminals;
- exhibition pavilions;
- aerospace engineering;
- landscape architecture;
- wellness architecture.

Default qualities:
- light;
- quiet;
- precise;
- warm;
- expansive;
- credible;
- maintainable.

Natural elements are infrastructural, not decorative.

Water, timber, plants, scanned landscape, gardens, and daylight should meaningfully shape the identity of the Spaceport.

---

## 14. Default Visual Prohibitions

Do not default to:
- generic cyberpunk;
- permanent neon;
- blue holographic UI;
- random pipes;
- random greeble;
- military bases;
- spaceship corridors;
- default ruins;
- RGB nightclub styling;
- incoherent AI concept-art structures.

The future should look usable.

---

## 15. Growth Philosophy

The Spaceport is not intended to be “finished.”

Its ideal form is continuous expansion:

```
ARRIVAL
→ BALLOON
→ T-HOUSE
→ MOVA
→ SENIA
→ ARCHIVE
→ FORUM
→ NEW STATIONS
→ EXTERNAL ROUTES
```

Each addition must justify:
- why it exists;
- who uses it;
- what happens there;
- why spatial form is necessary;
- which Stations it connects to;
- how long people stay;
- how it relates to existing VIRTURA work.
