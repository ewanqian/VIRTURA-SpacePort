## 知识领域概述

角色体系是沉浸式体验的软技能部分，包括导演思维、叙事设计、分镜头脚本、服务设计、刻意练习等。

## 子领域

### 导演思维
- 导演思维基础
- 如何把叙事和动画组织起来
- 不需要自己成为导演，知道这方面的知识就行

### 叙事设计
- 叙事设计基础
- 沉浸式叙事
- 空间叙事

### 分镜头脚本
- 分镜头脚本基础
- 怎么画分镜头
- 快速迭代的思维

### 服务设计
- 服务设计基础
- 沉浸式服务设计

### 刻意练习科目
- 预设困境 + 解决方案
- 针对性的刻意练习
- 快速迭代的思维
- 对照哪个知识块修正

## 课题

### 导演 vs 叙事 vs 动画
- 动画的逻辑：从头到尾一口气炫到底
- 舞台视觉的逻辑：找了很多参考，还是需要有导演才能的人，怎么把叙事和动画组织起来
- 这是不是又是一个新的，比如说角色体系？
