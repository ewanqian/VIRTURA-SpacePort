# VIRTURA 空间茶话会 Vol.0｜带上一段视觉，来客厅聊聊存档与远方

数字世界里的创作，常常像散落在虚空中的信号，静默等待回响。

这一晚，我们在一个有着阶梯与电视的实体客厅里，点亮其中一些信号。这不是正式发布会，而是一次更轻松、更接近朋友网络的非正式聚会。现场准备了尚未公开的影像、关于空间的构想、若干可即时把玩的设备，以及可以让谈话慢慢流动起来的茶水。

如果你也创作视觉、声音，或对数字空间的构建着迷，这一晚原本就是为你这样的人准备的。由于场地空间有限，当时的席位严格控制在 10-15 人之间，并以预先申请的方式进入。

## 当晚的大致流向

### 1. 抵达与开场

来访者陆续抵达，自由茶叙，由发起人简单开场，并让在场朋友先彼此认识。也欢迎参与者携带近期作品片段到现场交流。

### 2. 分享与漫谈

这一晚的核心围绕四个篇章展开：

1. 存档实践  
   从上海光影节穹顶艺术中心的建筑投影案例出发，讨论线下演出如何被感知、记录，并转化为可再次体验的数字副本。
2. 商业与沉浸式交互案例分享  
   由许思慧分享商业案例与沉浸式交互项目的内容与思考。
3. 数字远方  
   放映 `Segla 塞尼亚岛数字化旅居地` 的概念影片，讨论如何在数字维度构建可栖居之地。
4. 未来蓝图  
   首次展示 `太空气球 Balloon Live Space` 与「球立方」相关空间构想，并分享内容制作框架与开放合作标准。

### 3. 自由交流与设备体验

分享结束后转入自由交流。现场准备了 Apple Vision Pro、Meta Quest 3 与 VJ 演出控制器，供来访者体验、讨论和继续深入交流。

### 4. 夜间松弛时段

后续气氛转入更随性的视听松弛时段，由放放、钱誉文及朋友们继续分享视觉片段与音乐，整体停留时间随着现场交流自然延展。

- 周子凌（Murphy Nile）：跨媒体艺术家，与数字景观和远方构想相关
- 许思慧：交互艺术家，分享沉浸式交互与商业案例
- 钱誉文：本次活动发起人，围绕数字空间、音画互动与生态构建展开分享
- 沈轩：策展人、设计师、数字艺术家，作为核心成员共同推进 VIRTURA 的相关实践
