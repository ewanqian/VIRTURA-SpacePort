# Space Salon Activity Template

每一期 `Space Salon` 建议从这个模板开始。

## Front Matter

- `series`:
- `date`:
- `format`:
- `platform` or `venue`:
- `initiator`:
- `status`:
- `related project`:

## Directory Structure

```text
vol-xx-topic/
  README.md
  public-release.md
  internal-full-record.md
```

## README Should Answer

- 这期活动是什么
- 何时发生
- 以什么形式发生
- 对外版和内部完整版分别在哪
- 当前是否仍在补资料

## Public Release Should Hold

- 对外活动文案
- 简介版议题说明
- 适合报名页或推送页引用的文字

## Internal Full Record Should Hold

- 分享整理长文
- 更完整的对话脉络
- 可继续扩写、加脚注和二次编辑的原始整理
