# Space Salon

VIRTURA 空间茶话会系列档案入口。

`Space Salon` 更接近一个会反复开门的交流客厅，而不是一组冷冰冰的活动存档。

如果你是通过一次分享、朋友转发或活动海报来到这里，这里应该先让你知道：这个系列是什么、适合谁看、已经发生了什么，以及下一步该点哪里。

## 这个系列是什么

`Space Salon` 是 `VIRTURA` 持续进行中的交流活动线。

它不会默认每一期都要讲一个很大的概念。更多时候，它是大家一起放东西看、一起聊最近在做什么、一起拆一个问题、或者请朋友来分享最近的一段工作。

如果你只是想稳定地跟着我们的公共活动走，不一定要从这一页开始。更推荐先订阅：

- [VIRTURA 官方活动日历](https://lu.ma/VIRTURA)

`Space Salon` 是这条日历里的主要活动线之一，但不是全部。太空气球相关测试、展映和其他公开节点也会继续放在同一个入口里。

## 这里现在能看到什么

- 某一期活动的公开介绍

- 后续补充的图文、链接与现场资料

- 想知道团队最近在讨论什么、分享什么的人
- 想从旁听、交流或后续参与开始进入的人

## 接下来这条线怎么继续长

接下来的 `Space Salon` 不会往“团队介绍会”或“概念说明会”那边走。

更适合它的，是下面这 3 种状态：

### 1. 交流客厅

大家带最近在做的、最近看到的、最近还没想顺的东西来。

可以是一段视觉、一段音乐、一页网站、一个仓库结构、一个问题，或者只是一段你最近一直惦记的材料。

### 2. 一起放东西看

有时候比起正式分享，把一段东西放出来，再顺着现场一起聊，会更接近这个系列真正的气质。

### 3. 嘉宾分享或小范围方法交流

如果正好有朋友带着比较完整的一段工作来，也可以围绕那个主题展开，但重点还是交流和继续聊，而不是做一场过满的讲座。

## 接下来几期分别偏什么

1. `Vol.3`
   更偏 AI 热点之外的真实工作流，聊作品、过程、旧项目和仓库到底怎么整理。
2. `Vol.4`
   更偏一起放最近反复在看的东西，一块聊它为什么值得看。
3. `Vol.5`
   更偏把最近还没讲顺、还没做完的东西带来，继续拆、继续聊。

## 归档说明

`Space Salon` 当前作为 `VIRTURA-SpacePort` 里的公共活动档案线存在。

它不放在 `organization/`，而放在 `stations/`，是因为它更接近公共活动、交流站点和方法传播的发生现场，而不是组织管理栏目。
