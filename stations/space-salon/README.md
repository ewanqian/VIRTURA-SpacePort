# Space Salon

VIRTURA 空间茶话会系列档案入口。

`Space Salon` 更接近一个会反复开门的交流客厅，而不是一组冷冰冰的活动存档。

如果你是通过一次分享、朋友转发或活动海报来到这里，这里应该先让你知道：这个系列是什么、适合谁看、已经发生了什么，以及下一步该点哪里。

## 这个系列是什么

`Space Salon` 是 VIRTURA 持续进行中的交流活动线。

它通常围绕作品、方法、知识网络、工具实验或阶段性问题展开，形式可以是小范围分享、线上交流、闭门讨论或对外整理发布。

如果你只是想先稳定地跟着我们的公共活动走，不一定要从这一页开始。更推荐先订阅：

- [VIRTURA 官方活动日历](https://lu.ma/VIRTURA)

`Space Salon` 是这条日历里的主要活动线之一，但不是全部。太空气球相关测试、公开分享与其他活动节点也会继续放在同一个入口里。

## 这里现在能看到什么

- 某一期活动的公开介绍
- 已经发生的分享整理稿
- 后续补充的图文、链接与现场资料

## 适合谁看

- 想了解团队最近在讨论什么、分享什么的人

## 接下来这条线怎么继续长

接下来的 `Space Salon` 不会只是重复办“认识团队”的活动，而会更明确地沿着三类主题继续长：

- `交流客厅`
  让最近在做东西的人，有一个可以带着半成品、问题和阶段性想法进入的空间
- `方法分享`
  把存档实践、扫描、空间结构、知识网络这些主题拆成更能听进去的公共活动
- `项目转译`
  把一次现场、一个版本、一条研究线，慢慢转成更可阅读、更可回访的公开入口

所以接下来的 `Vol.3`、`Vol.4`、`Vol.5`，重点分别会偏向：

1. `Vol.3`
   先让社群互动和真实交流发生起来
2. `Vol.4`
   把“现场如何转成数字档案”讲清楚
3. `Vol.5`
   把扫描、3D 重建和空间记忆这条线拉到前台

## 归档说明

`Space Salon` 当前作为 `VIRTURA-SpacePort` 里的公共活动档案线存在。

它不放在 `organization/`，而放在 `stations/`，是因为它更接近公共活动、交流站点和方法传播的发生现场，而不是组织管理栏目。
