# Space Salon

VIRTURA 空间茶话会系列档案入口。

这里存放：

- 活动公告文案
- 分享记录与整理稿
- 后续补充的图文、链接与现场资料

## Archive Rule

`Space Salon` 当前作为 `VIRTURA-SpacePort` 里的公共活动档案线存在。

它不放在 `organization/`，而放在 `stations/`，是因为它更接近公共活动、交流站点和方法传播的发生现场，而不是组织管理栏目。

## Metadata Standard

后续每一期活动建议至少记录这些字段：

- `series`
- `date`
- `format`
- `platform` or `venue`
- `initiator`
- `status`
- `related project`

## Archive Structure

每一期活动建议保持同样的最小结构：

- `README.md`
- `public-release.md`
- `internal-full-record.md`

如果后续有图片、回放、报名页或补充材料，再继续追加二级文件。
