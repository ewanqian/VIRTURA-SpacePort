# Space Salon

VIRTURA 空间茶话会系列档案入口。

`Space Salon` 更接近一个会反复开门的交流客厅，而不是一组冷冰冰的活动存档。

如果你是通过一次分享、朋友转发或活动海报来到这里，这里应该先让你知道：这个系列是什么、适合谁看、已经发生了什么，以及下一步该点哪里。

## 这个系列是什么

`Space Salon` 是 VIRTURA 持续进行中的交流活动线。

它通常围绕作品、方法、知识网络、工具实验或阶段性问题展开，形式可以是小范围分享、线上交流、闭门讨论或对外整理发布。

## 这里现在能看到什么

- 某一期活动的公开介绍
- 已经发生的分享整理稿
- 后续补充的图文、链接与现场资料

## 适合谁看

- 想先通过交流活动认识 VIRTURA 的朋友
- 想了解团队最近在讨论什么、分享什么的人
- 想从旁听、交流或后续参与开始进入的人

## 第一次怎么进入

如果你是第一次看这个系列，建议按下面顺序进入:

1. 先看某一期的 `README.md`
2. 再看 `public-release.md` 了解对外版本
3. 如果你需要完整上下文，再看 `internal-full-record.md`

## 归档说明

`Space Salon` 当前作为 `VIRTURA-SpacePort` 里的公共活动档案线存在。

它不放在 `organization/`，而放在 `stations/`，是因为它更接近公共活动、交流站点和方法传播的发生现场，而不是组织管理栏目。

## 记录字段建议

后续每一期活动建议至少记录这些字段：

- `series`
- `date`
- `format`
- `platform` or `venue`
- `initiator`
- `status`
- `related project`
