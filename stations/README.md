# Stations

这里整理 `VIRTURA` 当前公开可进入的活动站点、交流入口、展映发布线与相关时间线。

`stations` 这一层更接近“发生现场”。它承接沙龙、交流客厅、线上实验、公开测试、线上展映，以及后续会继续生长出来的活动型与发布型入口。

## 先从哪里进入最自然

如果你是第一次来到这里，最推荐先做的一件事是：

- 订阅 [VIRTURA 官方活动日历](https://lu.ma/VIRTURA)

这个入口现在承担的工作很明确：

- 对外发布公开活动与报名入口
- 汇总近期可参加的节点
- 作为后续展映、测试和页面开放的统一入口

如果你平时使用 Luma，直接订阅这个主页，是当前最轻量的跟进方式。对第一次接触 `VIRTURA` 的朋友来说，这比一次性翻完整个仓库更自然，也更容易真的跟上后续发生的事。

## 这里现在主要有哪些内容

目前你会在这里看到 5 类比较明确的东西：

1. `Space Salon / 数字沙龙 / 交流客厅`
   偏交流、嘉宾分享、一起放东西看、一起聊最近在做什么。
2. `太空气球 / Baloon Live Space`
   偏线上 live set、音画实验、演出空间测试和共测。
3. `MOVA / Museum of Virtual Art`
   偏线上展映、数字展览和作品观看入口。
4. `在制内容审计会`
   偏把正在做的东西拿出来，一起挑问题。
5. `Digital Library / Digital Stage 公开说明`
   偏围绕仓库、归档、页面前台和内容管理做短而实用的公开说明。

另外还会穿插：

- `观看入口开放`
- `页面上新`
- `公开测试`

## 我们为什么把活动入口放这么前

不是每个人都会通过“合作申请”来认识 `VIRTURA`。

很多人只是对这个网络、这些作品、这些讨论方向感兴趣，想先旁听一次活动，看看最近在发生什么，或者慢慢找到自己真正想继续靠近的入口。

所以这里不是一个单纯的活动列表，而是一个可以长期关注的公共前台。

## 除了日历，还会从哪里收到更新

- 小红书：搜索 `EWANCT前宇文`
- 小红书：搜索 `VIRTURA`
- 私信可进一步进入小红书群，群内也会同步活动链接与临时更新

## 当前活动与发布线

### 1. 太空气球 / Baloon Live Space

这条线承接线上演出空间、音乐与音画实验、公开测试以及后续更完整的线上线下演出节点。

它最早能追到 `2022` 年的 `VRChat` 地图构想。现在公开活动里看到的 `Alpha` 和 `Session`，是这条线被收回到更轻的三维内容直播间之后，第一批真正对外开放的测试。

当前入口：

- [太空气球 / Baloon Live Space 系列页](./baloon-live-space/README.md)
- [太空气球 Baloon Live Space Alpha 测试｜电子人 × E1 线上数字舞台 live set](https://luma.com/go6kxnnw)

### 2. Space Salon / 数字沙龙 / 交流客厅

这条线承接线下分享会、线上漫谈、小规模交流、一起放内容看和邀请制嘉宾分享。

当前代表入口：

- [Space Salon](./space-salon/README.md)

### 3. MOVA / Museum of Virtual Art

这条线承接线上展映、作品观看室、轻量展览与从 GitHub library 快速转成公共展示入口的发布节点。

当前代表入口：

- [MOVA](./mova/README.md)

### 4. 在制内容审计会

这条线更偏创作中的问题整理、结构批评、页面与版本复盘。

它不是成果展示，也不是互相捧场，而是认真看问题到底出在哪。

当前代表入口：

- [在制内容审计会](./content-audit/README.md)

### 5. Digital Library / Digital Stage 公开说明

这条线更偏围绕 GitHub 仓库、知识网络、归档结构、页面前台和 AI 时代的内容管理，做短而实用的公开说明。

重点不是卖概念，而是讲明白一套真的能继续工作的组织方法。

当前代表入口：

- [Digital Library / Digital Stage](./digital-library-stage/README.md)

## 除了活动，还会继续出现什么

后续这个时间线不只会加活动，也会逐步加入：

- 公开测试开启
- 观看入口开放
- 页面或场景上新
- `MOVA` 线上展映与观看室上线
- 仓库和知识网络相关的公开说明入口

这样 `stations` 才不只是“归档发生过什么”，也能持续承接“接下来能看什么、参加什么、继续进入什么”。
