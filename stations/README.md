# Stations

这里整理 VIRTURA 当前公开可进入的活动站点、交流入口与相关时间线。

`stations` 这一层更接近“发生现场”：它承接沙龙、交流客厅、线上实验、公开测试，以及后续会继续生长出来的活动型入口。

## VIRTURA 官方活动日历

当前 VIRTURA 的官方活动日历使用 Luma 维护。

它承担的主要工作是：

- 对外发布公开活动与报名入口
- 汇总近期可参加的节点
- 作为后续活动更新的统一入口

如果你想用最简单的方式跟着我们的活动走，优先从这里进入：

- [Luma 公开主页](https://luma.com/user/usr-TS35aDrheI8Axqr)
- [VIRTURA 空间茶话会 Vol.0｜带上一段视觉，来客厅聊聊存档与远方](https://luma.com/iehkdjr0)
- [太空气球线上演出空间 Alpha 测试](https://luma.com/go6kxnnw)

如果你平时使用 Luma，直接从这组入口关注后续活动更新，是当前最轻量的跟进方式。对第一次接触 VIRTURA 的朋友来说，先加入这条活动日历，也比一次性翻完整个仓库更容易建立联系。
