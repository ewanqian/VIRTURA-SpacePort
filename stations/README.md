# Stations

这里整理 VIRTURA 当前公开可进入的活动站点、交流入口与相关时间线。

`stations` 这一层更接近“发生现场”：它承接沙龙、交流客厅、线上实验、公开测试，以及后续会继续生长出来的活动型入口。

## VIRTURA 官方活动日历

当前 VIRTURA 的官方活动日历使用 Luma 维护。

它承担的主要工作是：

- 对外发布公开活动与报名入口
- 汇总近期可参加的节点
- 作为后续活动更新的统一入口

如果你对这个创作网络感兴趣，最推荐先做的一件事，就是订阅这个入口：

- [VIRTURA 官方活动日历](https://lu.ma/VIRTURA)
- [VIRTURA 空间茶话会 Vol.0｜带上一段视觉，来客厅聊聊存档与远方](https://luma.com/iehkdjr0)
- [太空气球线上演出空间 Alpha 测试](https://luma.com/go6kxnnw)

如果你平时使用 Luma，直接订阅这个主页，是当前最轻量的跟进方式。对第一次接触 VIRTURA 的朋友来说，这比一次性翻完整个仓库更自然，也更容易真的跟上后续发生的事。

## 我们为什么把活动入口放这么前

不是每个人都会通过“合作申请”来认识 VIRTURA。

很多人只是对这个网络、这些作品、这些讨论方向感兴趣，想先旁听一次活动，看看最近在发生什么，或者慢慢找到自己真正感兴趣的入口。对我们来说，持续举办公共活动，本身也是一种公开发声与持续交流的方式。

所以这里不是一个单纯的活动列表，而是一个可以长期关注的公共入口。
