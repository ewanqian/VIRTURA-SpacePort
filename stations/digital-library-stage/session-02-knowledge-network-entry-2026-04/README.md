## 本期要点

- 这一期从 `SpacePort` 的知识网络出发，讨论入口设计和阅读坡度
- 重点不是“目录做多大”，而是别人进来之后怎么不迷路
- 知识网络只有接到活动、项目和前台，才会变成真的公共入口

## 本期适合处理的问题

- 知识页很多，但别人点进去还是掉出来
- 目录看起来完整，真正有用的线路却不明显
- 活动入口、项目入口和研究入口彼此断开
- 页面分层太重，第一次访问的人不知道该先去哪
