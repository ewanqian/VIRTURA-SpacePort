# Digital Library / Digital Stage

这里是 `Digital Library / Digital Stage` 的站点总入口。

它不是单纯的活动系列页，而是 `VIRTURA` 当前围绕仓库、归档、前台和内容分发持续展开的一条公开说明线。

这条线当前主要在处理四个问题：

1. 作品、过程、材料和旧项目到底怎么整理
2. 一个库为什么不只是目录，而要能继续工作
3. 一个前台为什么不只是好看，而要能真正带人走下去
4. AI 到底在哪些环节能帮忙，哪些判断还必须自己做

---

## 当前状态

- Station 状态：`运行中`
- Web 状态：`md-only`
- 3D 准备：`准备中`

它已经不只是“几场公开说明”，而是在逐步变成 `SpacePort` 的前台结构说明层。

---

## 这个 station 现在负责什么

`Digital Library / Digital Stage` 当前主要负责：

1. 解释 `SpacePort` 里的库、前台、活动和资料库怎么互相接起来
2. 把内容整理成库，再把库整理成前台
3. 为网页前台、`Digital Stage`、后续 `3D frontstage` 准备更稳定的组织逻辑
