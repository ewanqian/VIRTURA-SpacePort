# Digital Library / Digital Stage

`Digital Library / Digital Stage` 是 `VIRTURA` 当前围绕仓库、归档、前台和内容分发持续展开的一条公开说明线。

它不打算把 “AI 时代的内容管理” 讲成一套很玄的概念，而是想把几件具体的事讲明白：

1. 作品、过程、材料和旧项目到底怎么整理
2. 一个库为什么不只是目录，而要能继续工作
3. 一个前台为什么不只是好看，而要能真正带人走下去
4. AI 到底在哪些环节能帮忙，哪些判断还必须自己做

## 这条线为什么重要

对 `VIRTURA` 来说，这条线不是配角。

作品、活动、展映和知识网络如果没有一套能继续工作的组织方式，后面所有公开发布都会越来越重，越来越乱，越来越依赖临时记忆。

所以 `Digital Library / Digital Stage` 本质上在做两件事：

- 把内容整理成库
- 把库整理成前台
