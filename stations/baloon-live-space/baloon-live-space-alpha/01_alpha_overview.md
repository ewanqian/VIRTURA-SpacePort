# Alpha Overview / Alpha 概览

## What This Is / 这是什么

**Baloon Live Space Alpha** 是"太空气球 / Baloon Live Space"系列的第一轮公开测试。

它不是正式发布，而是一次线上数字舞台结构实验。这次测试的重点不是一次做满所有功能，而是先把最基本的观看链路跑通，确认一场基于实时音频驱动、空间视觉呈现和直播输出的 live set 是否成立。

## What This Alpha Verifies / 这次主要验证什么

- 观众是否能顺利进入并持续观看
- 音乐、画面和空间是否能建立有效关系
- 一套轻量实时系统是否足够稳定
- 单人操作的线上数字舞台是否成立
- 这条线是否值得继续发展

## Why This Folder Exists / 为什么要有这个目录

这个 `baloon-live-space-alpha` 目录不是为了放完整项目，而是为了存放**当前阶段有效的文档**。

这里存的内容，都是后面还会继续引用、继续补充的基础材料。它更像一个阶段性档案层，帮助后续：

- 回顾这次测试
- 提炼当前有效的方法
- 给朋友或合作方快速了解创作过程
- 为后面的系统升级提供引用依据

## Current Judgment / 当前判断

这次 Alpha 最重要的成果，不是某个画面，而是验证了一条基本成立的系统路径：

**音频输入 → Arena 实时处理 → Unity 空间呈现 → 直播输出**

这还不是最终版本，但已经是一个可继续发展的原型。
