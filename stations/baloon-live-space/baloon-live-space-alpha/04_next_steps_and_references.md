# Next Steps and References / 下一步与参考

## Next Steps / 下一步

接下来主要往四个方向推进：

### 1. 空间质量升级

- 从 URP 逐步测试到 HDRP
- 加更好的雾气
- 尝试动态 GI
- 整体提升空间氛围和舞台感

### 2. 表演系统升级

- 补更多 state 状态定义
- 加 Timeline 或更明确的段落切换机制
- 结合 MIDI 控制
- 扩展 clips 系统（按类型分类整理，建立预设库）
- 继续强化 BPM / tap / resync 的组织能力

### 3. 节目包装方向

补"电台感"或"栏目包装感"的部分。比如预置一些像 "You are listening to ..." 这样的片段，让它更像一个正在持续发生的线上节目，而不只是纯 visualizer。

### 4. 多空间模板

不只保留一个场景，尝试不同空间，慢慢长出几种不同的 live set 模板。

## References / 参考

### 1. Ryuichi Sakamoto × Alva Noto

坂本龙一与 Alva Noto 的合作线对我影响很大——包括演出形式、极简精密的审美、冷静但有推进感的结构。

### 2. By This River

这首歌和相关演出经验，是这次 Alpha 审美的一部分线索。以前对这类电子音乐了解不多，但后来慢慢意识到它对理解声音和视觉的关系影响很大。

### 3. 2022–2024 期间整理过的舞台场景

这次 Alpha 不是凭空开始的，它和之前几年整理过的舞台场景、直播海报、空间构想有关。这次只是把这些东西收回到一个更轻的线上数字舞台框架里。

### 4. Instagram 上的舞台参考

前阵子看到一种红色舞台灯照着黑铁架和人群的空间，明显是偏虚幻引擎做的。它给我的启发是：有时候人群不必特别精细，但**灯光、烟雾、密度和演出氛围先成立，就已经非常有效**。

## 当前结论

这次 Alpha 最重要的，不是证明一个大而全的系统已经完成，而是证明了一条**轻量、稳定、可表演、可继续扩展**的线上数字舞台路径是成立的。
