## 这场 Alpha 实际在验证什么

这不是一场“正式上线”的发布会，而是 `Baloon Live Space` 第一轮对外可见的结构测试。

这场活动最重要的，不是一次把所有互动功能讲满，而是先把一条最基本的线上观看链路跑通：

1. 观众能不能顺利进入
2. 音乐和视觉能不能稳定同步
3. 浏览器里的三维内容直播间，能不能先成立为一个可看的舞台
4. 大家看完之后，愿不愿意继续回来参加下一轮

## 本场 lineup

- 音乐：`电子人`
- 视觉：`Ew1（Ewan Qian 钱誉文）`

这场 live set 的结构更接近一条试演中的线上舞台样稿：重点看实时视觉怎样跟随节拍、`BPM` 和音乐段落变化，而不是先做一套很重的社交壳。

### 关于这次合作

电子人说：「欢迎监督我们的创作」

这次 live set 前半小时放的是电子人的三首歌——每首歌的状态都很鲜明，动静层次清楚，节拍特别适合做视觉化。

前期我们也沟通了一下想法：

- 电子人对视觉上的偏好：色块、基础数字化感
- 我的方向：擅长用 Arena 的音频检测实时搭简单视觉元素，加查找边缘等特效做成动态平面构成，跟节拍高度融合

视觉上的核心策略是：**细节少，卡准拍子就行**——配合推移、continue 等功能，再加上对之前视觉分析的一些抽象理解，结合 Unity 场景后，给人一种「在螺旋龙卷风风暴中游走」的状态。

视觉切片我也在朋友圈分享了，后面估计会总结出一个视频。

## 前情提要

`Baloon Live Space` 最早可以追到 `2022` 年那一版 `VRChat` 地图构想。

当时的方向更强调虚拟化身、在同一空间里看演出，以及更完整的虚拟场景临场感。那个方向没有被否定，但在真正对外测试之前，我们先遇到了一个很现实的问题：不是每个想来看演出的人，都愿意先下载客户端、配置环境，再学习一套新的进入方式。

所以这一轮 Alpha 的判断非常直接：

- 先把入口压轻
- 先让作品和现场成立
- 先把观看和反馈链路跑通

## 本场最值得收集的反馈

- 进入流程哪里卡
- 画面和音乐同步感哪里有效
- 哪一类镜头或视觉段落会让人愿意停下来继续看
- 浏览器观看有没有明显性能瓶颈
- 作为音乐人、VJ 或观众，会不会想把这条线继续带到下一次
