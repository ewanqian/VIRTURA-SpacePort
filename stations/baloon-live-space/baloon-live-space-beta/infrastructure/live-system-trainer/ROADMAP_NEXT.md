# ROADMAP NEXT / 下一版本路线图

## 当前版本定位

- 版本：`v2-realistic-ui`
- 阶段：`beta prototype`
- 目标：从“可演示”进入“可训练”

---

## v2.1 - Logic Fix

### 目标

让十个关卡真正稳定可玩。

### 任务

- 修复完成判定不稳定
- 增加每步 checklist 高亮
- 增加“还差什么”提示
- 修复重置逻辑

---

## v2.2 - Briefing & Debrief

### 目标

让每关更像真实排练而不是软件说明。

### 任务

- 每关开头加入 brief
- 每关结尾加入 debrief
- 写清楚现实映射
- 加入“为什么要练这关”

---

## v2.3 - Stress Mode

### 目标

把演出里会遇到的压力引进来。

### 任务

- 随机 source lost
- 随机 drift
- 超时失败
- fail-safe 未设置直接扣分

---

## v2.4 - Controller Pass

### 目标

让控制器层更像真实训练。

### 任务

- 明确 AKAI 型号
- 还原更接近真实 pad / fader 布局
- 加入动作过量提醒
- 加入手感评分

---

## v3.0 - Template System

### 目标

从统一练习器进入“多艺人模板”阶段。

### 模板

- ambient / drone
- club / DJ
- hybrid live / experimental

### 每个模板应包含

- default notes
- default fail-safe
- default controller map
- default level emphasis

---

## 更远的版本

### v3.x

- Notes 导入导出
- 录屏模式
- 速通排行榜
- 教学模式

### v4.x

- 接入更真实的 show file 概念
- 尝试加入 OSC address view
- 允许“模拟 patching”更细化

---

## 不急着做的事

- 过度追求原软件 UI 复刻
- 真远程控制接口
- 复杂后端
- 太重的框架迁移

保持它轻、清楚、可分享，仍然是对的。
