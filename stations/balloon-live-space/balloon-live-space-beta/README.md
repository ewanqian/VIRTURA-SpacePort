## 我的当前定位 / 自我认知

承认自己还是个新手——不会 TD design，Arena 也只用基础内容。没关系，就重新刷，像高手一样积累时长。

### 核心理解

很多高手的现场演出特点：
- 时长很长
- 很悠哉，慢慢通过设备调状态
- 一遍一遍重复，像用刷子刷一面很大的墙
- 以前需要很多人一起刷，现在借助 AI 可以做到

## 日常练习方式

### 绑定听音乐行为

> 每天开工程 1-2 小时，放点音乐，能点直播就点直播。

- **和听音乐绑定**：不要把它当工作，就是日常听音乐
- **天然段落**：一张黑胶 20 多分钟，就是一段
- **挂着就行**：白天放着，忍不住想改就改，但不要影响工作
- **有思考就记**：不一定每次都要产出，有想法就记录下来

### 练习目标

- 积累现场时长
- 优化手感（Arena / 直播流 / 状态切换）
- 让系统更稳、更顺手
