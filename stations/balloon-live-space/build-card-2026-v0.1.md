# BUILD CARD — A02 Balloon Live Space v0.1

## Identity

- ID: A02
- Existing Station: Balloon Live Space / 太空气球
- Role: live AV venue, browser stage, broadcast and rehearsal infrastructure
- Class: H96 / Major
- Status: Existing line entering spatial rebuild
- Priority: P1 after A00

This Build Card does not replace the existing Balloon archive. It defines the 2026 spatial product version.

## Main test question

Can Balloon become a reusable online venue rather than a one-off virtual stage?

## Program

- Arrival Deck
- Main Balloon Chamber
- DJ / AV Booth
- Audience Ring
- Broadcast Surface
- Rehearsal / Soundcheck Room
- Backstage
- Replay Archive Portal
- Technical Bridge to SceneForge / live systems

## Core spatial idea

The “balloon” should not be interpreted as a literal cartoon balloon.

It is a pressure / membrane / expansion idea:
- large suspended performance volume;
- lightweight shell;
- ring circulation;
- expandable media surface;
- atmosphere that can change radically by performance state.

Exterior and connector structure should remain believable and modular.

## Ports

- primary public route from A00;
- archive/media route;
- backstage/logistics route;
- optional future external-event route.

## Live architecture

Separate:
1. small interactive room;
2. one-to-many public broadcast.

Do not design the networking model as if every audience member must be peer-to-peer connected.

## Visual language

Amplify:
- membrane;
- tension;
- ring;
- suspension;
- dark acoustic surfaces;
- large graphic projection;
- stage machinery used selectively;
- strong contrast with Arrival Terminal.

Avoid:
- generic EDM club;
- permanent RGB rainbow;
- futuristic nightclub clichés;
- spaceship hangar.

## Interaction

v0.1:
- enter venue;
- choose main chamber / booth / archive;
- map local or streamed video to a performance surface;
- switch simple cue states.

Later:
- artist room;
- invite link;
- audience presence;
- spatial audio;
- live schedule;
- replay.

## Performance quality gate

- stage reads clearly at human scale;
- video surface remains legible;
- cue changes do not destroy navigation;
- WebXR quality tier exists;
- live media path can be disabled without breaking the Station;
- archive remains accessible outside the 3D room.
