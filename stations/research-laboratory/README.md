# Research Laboratory

这里是 `Research Laboratory` 的站点总入口。

它负责的不是产品展示，而是研究母本层：

- 研究问题定义
- 实验过程记录
- 路线比较
- 模块判断
- 方法文档沉淀

## 这个 station 现在负责什么

`Research Laboratory` 当前主要负责：

1. 作为 `SpacePort` 的研究基础层，沉淀长期有效的方法与判断
2. 承接实验、路线比较和模块决策，而不是直接承担产品前台
3. 给 `Skill Forge`、`Baloon Live Space`、`Digital Library / Digital Stage` 等站点提供母本
