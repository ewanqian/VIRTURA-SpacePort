# 当前进度归档：Web-first 路线、模拟器方向与创作网络优势判断

这份文档用于归档本轮关于产品路线、研究优先级、创作网络优势与后续组织工具的阶段性判断。

它不是最终宣言，而是当前的工作共识版本，供 Research Laboratory、SpacePort、Newsroom、portfolio 与后续 Agent 协作继续引用。

---

## 1. 路线收束结论

当前路线正式收束为：

**Web-first / MR-optional**

具体优先级为：

1. **P0：网页端交互出版物 / 节点化阅读器**
2. **P1：训练模拟器 / 智力装备**
3. **P2：项目推演器 / Digital Library / Digital Stage 工具层**
4. **P3：MR / Vision Pro 展示层（可选）**

核心判断：

- 设备不是需求本身
- 头显不是主需求
- 真正的需求是更快理解、更快练习、更快协作、更快推演与更快复盘
- MR 不取消，但不再作为当前阶段的主产品方向

---

## 2. 为什么做这个判断

本轮讨论中，路线判断进一步明确：

- 如果内容、动线、节点关系和训练结构本身还没有成立，那么把内容搬进头显，往往只是把混乱搬到更贵的设备里
- 真正值得长期建设的，是可进入、可练习、可部署、可协作的交互系统
- 网页端更适合作为知识网络长成应用态的基础层

因此，当前产品与研究重点应从“设备导向”转向“组织方式导向”。

---

## 3. 当前最值得做的三类产品

### 3.1 交互出版物
不是 PDF，不是 PPT，也不是视频教程，而是一种可点击、可展开、可跳转、可重组的阅读系统。

适合做：
- Research Reader
- 节点化理论图谱
- 港口内容分析阅读器
- 太空站研究节点浏览器

### 3.2 训练模拟器 / 智力装备
不是把知识讲一遍，而是让使用者在限制条件、节点选择、任务目标与即时反馈中“部署知识”。

适合做：
- 新媒体艺术家模拟器 2.0
- 演出视觉系统训练器
- AI 短片流程模拟器
- 10 天 10 关卡认知训练模拟器

### 3.3 项目推演器
把展览、演出、文旅、教学或数字内容项目中的判断逻辑拆解出来，形成可比较、可复盘、可协作的推演系统。

适合做：
- 演出项目推演器
- 展览推演器
- 文旅方案推演器
- Digital Library / Digital Stage 管理模拟器

---

## 4. 当前不优先做的内容

当前阶段不优先做：

- 大型世界观外壳
- 高成本 3D 建模沉浸场景
- 头显优先的商业包装
- 一开始就做“平台”
- 复杂多端同步先行

这些方向不是永久取消，而是应放在当前主线跑通之后再进入。

---

## 5. 创作网络当前最有价值的优势

本轮分析后，当前团队 / 创作网络最值得继续放大的，不是单点技术，而是下列组合优势：

### 5.1 低成本高密度迭代
- 用 Blender / 实时引擎可直接出效果图与预演
- AI 短片、绿幕抠像、预可视化与轻量制作可快速闭环
- 不依赖传统大公司的多层分包链路

### 5.2 创作语言与工具链由同一批人掌握
- 创意判断、视觉语言、实时系统、工具实验、AI 工作流与演出经验可以在同一协作网络中闭环

### 5.3 知识网络可转成智力装备与工具
- 不是只做项目，而是可把项目经验反过来沉淀成训练器、模拟器、阅读器与方法论系统

### 5.4 Web-first 的分发与协作优势
- 更容易传播
- 更适合 GitHub 版本化
- 更适合多人协作
- 更适合 Agent 读取、引用与后续推演

---

## 6. 当前最值得从市场中“抢”的几块

### 6.1 前期方案与预演
相较于传统公司，当前创作网络更适合用低成本做出：
- 更快的空间预演
- 更快的视觉样片
- 更快的交互逻辑图
- 更快的白天 / 夜晚双模式推演

### 6.2 白天展览 / 晚上演出的双模式空间系统
这类项目不应只卖“沉浸式空间”，而应包装为：

**可切换的内容运营空间系统**

白天：导览 / 展览 / 品牌 / 教育 / 轻互动  
晚上：live / VJ / 艺术家合作 / 特别放映 / 派对内容

### 6.3 教育 / 培训 / 团队演练
训练模拟器与网页节点化系统非常适合进入：
- 学校实训
- 工作坊
- 创作者教育
- 团队 onboarding
- 技术训练与流程演练

---

## 7. Apple Vision Pro / MR 的重新定位

Apple Vision Pro 与 MR 方向并未被删除，而是被重新定位为：

- 高级样板间
- 展示增强层
- 可选空间计算体验层
- 已有内容和动线成立后的 bonus point

也就是说：

不是先卖 MR，而是先把空间、展览、品牌、产品或训练系统组织成立，再决定是否接入 MR 作为高级版本。

---

## 8. 当前最缺的三张表

为了把“去中心化创作网络”从感觉推到可计算状态，当前必须补三张表：

### 8.1 成员能力矩阵
至少记录：
- 会什么软件
- 会到什么等级
- 能独立做什么
- 不能做什么
- 每周稳定投入时长
- 适合什么项目阶段
- 是否适合带人 / 对客 / 做模板

### 8.2 生产链时间 / 成本矩阵
至少记录：
- 效果图
- 预演视频
- AI 短片
- 抠像
- 场景交互
- 大屏内容
- 现场演出系统
- 网页交互出版物
- 模拟器原型

每项需要有：
- 最快工期
- 正常工期
- 负责人
- 外包需求
- token / 渲染 / 软件授权成本
- 风险点

### 8.3 业务模型矩阵
至少分为：
- 方案设计费
- 制作执行费
- 运营活动费
- 工具 / 系统费
- 长期维护费

## 12. 一句话总结

当前阶段最重要的不是继续追逐某个设备热点，而是把知识网络、项目经验、空间方法与创作协作，转化为：

**Web-first 的交互出版物、训练模拟器、项目推演器与可部署智力装备系统。**

MR 与空间计算仍然保留，但它们现在的正确位置，是系统成立后的增强层，而不是系统本身。
