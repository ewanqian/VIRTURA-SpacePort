# Skill Forge Skill Tree

---

## Layer 0｜治理与记忆层

### Governance
- `AGENTS.md`
- `MEMORY.md`

### Memory
- `patterns.md`
- `archive-rules.md`
- `publishing.md`

- `naming-conventions.md`

- 归档原则

---

## Layer 1｜基础治理技能

### Bootstrap Skills
- `doc-archive`
- `salon-publish`
- `project-checkpoint`

### 作用
让系统具备：
- 原始材料进入仓库的能力
- salon 内容发布能力
- checkpoint / handoff 能力

### 当前状态
已建立，仍属于 bootstrap。

---

## Layer 2｜核心压缩与同步技能

### P0 Core Skills
- `longform-to-skill-card`
- `route-update-sync`
- `training-simulator-framework-builder`

### 作用
这是 Skill Forge 当前的真正主干：

#### `longform-to-skill-card`
把母本压缩成可执行技能。

#### `route-update-sync`
把路线变化同步到不同仓库层。

#### `training-simulator-framework-builder`
把课程、知识网络和工作流转成训练模拟器结构。

### 当前状态
已建立，active。

---

## Layer 3｜应用化技能

### P1 Applied Skills
- `research-reader-builder`
- `project-scenario-engine-builder`

### 作用
把知识与项目逻辑进一步转成可运行的应用结构。

#### Reading Path
理论 / 研究块 → 节点化阅读器 → 交互出版物

#### Scenario Path
项目逻辑 / 制作条件 → 推演框架 → 项目推演器

### 当前状态
已建立，active。

---

## Layer 4｜中枢协调技能

### 待建立
- `skill-router`
- `source-to-public-handoff`
- `merge-gate-reviewer`

### 作用
让 Skill Forge 具备：
- 路由能力
- handoff 能力
- 审查能力
- 双 agent 协作能力

### 为什么重要
没有这一层，skills 只是单点模块。  
有了这一层，Skill Forge 才开始变成一个可调度系统。

---

## 发展逻辑

当前 Skill Forge 的发展逻辑不是"越多越好"，而是：

1. 先有治理与记忆
2. 再有基础治理技能
3. 再有核心压缩与同步技能
4. 再有应用化技能
5. 再补中枢协调层
6. 最后扩展发布与运维
