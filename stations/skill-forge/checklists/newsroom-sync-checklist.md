# Checklist: Newsroom Sync

Use when a source-of-truth update should become a public-facing article or summary.

## Steps
1. Read the source-of-truth file.
2. Identify one core judgment only.
3. Rewrite it for first-time readers.
4. Keep it readable and public-facing.
5. Add links back to the source when relevant.
6. Do not dump internal process as public writing.
