# Skill: Training Simulator Framework Builder

## What this skill does
This skill converts a course outline, workflow, or knowledge-network block into a web-first training simulator structure.

It is designed to help turn abstract knowledge into a staged system of levels, tasks, validation logic, and deployable skill blocks.

## When to use it
Use this skill when:

- a course should become a simulator
- a workflow should become a training path
- a knowledge network should become a playable structure
- a workshop needs clearer progression
- a learning system needs levels, tasks, and measurable outputs

## Required input
- source material (course outline, workflow, theory block, or archive)
- target users
- expected learning or production outcome
- whether it is exploratory, educational, or production-facing

## Steps
1. Read the source material completely.
2. Identify the main user type.
3. Identify the main target ability, not just the topic.
4. Break the source into skill blocks.
5. Convert the skill blocks into a level structure.
6. For each level, define:
   - goal
   - task
   - input
   - expected output
   - check or scoring logic
7. Make the framework modular and web-first.
8. Avoid heavy worldbuilding unless it directly improves training.
9. Output the framework in a form that could later become:
   - a reading system
   - a task simulator
   - a web tool
   - a scene or training runtime

## Good output
A good output:
- is level-based
- is testable
- is teachable
- preserves the original logic
- turns knowledge into deployable actions
- can later be implemented as a web-first simulator

## Failure modes
- keeps the source as a lecture outline only
- creates a beautiful structure with no validation logic
- focuses on theme before function
- makes levels too abstract to test
- skips user type and expected outcome
