# Prompt Pack: Route Update Sync

Use this prompt when a route judgment changed and related repositories need coordinated updates.

## Prompt

Read the current route archive and extract:

- the main judgment
- what changed
- what this affects
- what should not be changed

Then generate four outputs:

1. SpacePort source-of-truth update suggestion
2. Newsroom publication draft
3. portfolio light update suggestion
4. Collective light update suggestion

Rules:
- keep SpacePort as source-of-truth
- keep Newsroom readable
- keep portfolio personal
- keep Collective concise
- do not duplicate full research text everywhere
