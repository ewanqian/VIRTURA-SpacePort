# Prompt Pack: Training Simulator Framework Builder

Use this prompt when a course outline, workflow, or knowledge network needs to become a training simulator structure.

## Prompt

Convert the source material into a training simulator framework.

Output should include:

1. simulator purpose
2. target users
3. level structure
4. skill blocks
5. required inputs
6. scoring or validation logic
7. final deliverables

Rules:
- do not start from heavy worldbuilding
- prefer web-first modular structure
- turn knowledge into deployable actions
- keep levels teachable and testable
