# Prompt Pack: Longform to Skill Card

Use this prompt when a longform research note or route archive needs to be compressed into a structured skill card.

## Prompt

Read the source-of-truth document first.

Your task is not to summarize it loosely, but to convert it into a reusable skill card.

Output must contain:

1. What this skill does
2. When to use it
3. Required input
4. Steps
5. Good output
6. Failure modes

Rules:
- preserve the main judgment
- remove repetition
- keep input/output explicit
- do not invent new theory
- do not publish as public-facing text
