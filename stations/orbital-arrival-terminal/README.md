# A00 — Orbital Arrival Terminal / 轨道到达港

> Station ID: A00  
> Class: H96 / Major  
> Status: Foundation  
> Canonical role: VIRTURA Spaceport public arrival infrastructure

A00 is the first spatial Station of the 2026 Spaceport rebuild.

It is not a sci-fi lobby used only for atmosphere. It is the actual orientation layer connecting the public web frontstage, the 3D campus, WebXR entry, station routing, current events, meeting access, and future live rooms.

## Public role

A first-time visitor should understand four things within roughly 30 seconds:

1. where they are;
2. what is happening now;
3. which destinations are available;
4. whether they want to Browse, Walk, enter XR, or Join a live/social destination.

The 2D frontstage and the 3D Arrival Terminal are two interfaces to the same Station data.

## Primary spatial sequence

```
WEB FRONTSTAGE
   ↓
ARRIVAL THRESHOLD
   ↓
ORIENTATION HALL
   ↓
ROUTE TABLE / CURRENT PROGRAM
   ↓
DESTINATION PORTS
   ├── MOVA
   ├── BALLOON
   ├── T-HOUSE
   ├── SENIA
   ├── LAB
   └── ARCHIVE / FORUM
```

Fast travel is canonical. Visitors are not required to physically walk through every connector.

## Design direction

A00 should feel closer to:

- contemporary airport lounge;
- ferry / cruise terminal;
- public museum lobby;
- scientific research campus;
- premium technology showroom;

and farther from:

- spaceship cockpit;
- military command center;
- blue hologram control room;
- neon cyberpunk station;
- random spaceship corridor.

## Relationship to the old 2114 entrance

The old VIRTURA2114 reception center remains a historical visitor-system precedent. A00 does not copy its Collapse Era fiction, but preserves the useful idea that different visitors can receive different routes.
