# 在制内容审计会

`在制内容审计会` 是 `VIRTURA` 当前最直接的一条问题拆解线。

它不服务于成果展示，而服务于判断：

- 哪个页面没讲清
- 哪个场景入口不自然
- 哪个版本关系讲糊了
- 哪个前台看起来完整，实际还是空的

## 为什么这条线值得保留

很多团队会做分享、会做发布、会做展映，但不会保留“认真挑问题”的公共机制。

对我们来说，这条线的价值就在这里：它让很多还没完成、还没说顺、还没组织好的东西，有一个被继续工作的机会。

## 当前工作项目

这条线当前已经接住一项更基础的工作：

- [SpacePort 网页化与 3D 升维准备路线图](../../docs/spaceport-web-3d-preparation-roadmap.md)

这份路线图主要整理：

- `stations` 怎样统一出现在网页前台
- 每个 `station` 怎样补齐文字界面和 tracker
- 现有技术债、结构债和后续 `3D` 准备项怎样一起收
