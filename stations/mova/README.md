# Museum of Virtual Arts / MOVA

这里是 `MOVA` 的站点总入口。

它承接的不是单个线上展览页面，而是一条持续整理中的数字展映与观看入口生产线。

当前更适合把它理解为：

- 线上展映入口
- 观看室组织层
- 数字展览生产站
- 后续可继续复用的策展前台

---

## 当前状态

- Station 状态：`生长中`
- Web 状态：`md-only`
- 3D 准备：`准备中`

这条线已经从“展映方向”长成一个有索引、有单展页、能继续做模板化的 station。

---

## 这个 station 现在负责什么

`MOVA` 当前主要负责：

1. 把作品、研究、archive 和活动收成真正能进入的观看路线
2. 把单次展映整理成可复用的数字展览生产结构
3. 为后续网页前台与空间化展映入口准备统一组织方式
