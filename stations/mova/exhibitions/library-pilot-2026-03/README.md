# 从库到展：VIRTURA 数字空间研究摘编

> `MOVA` 试运行展
> 状态：open

这是一场很轻量的线上试运行展。

它的目的不是一次性展示 VIRTURA 的全部，而是测试另一种更适合当前阶段的公共入口：

把 GitHub 里已经存在的作品、研究、知识网络和活动归档，组织成一条更容易观看的路线。

## 这场试运行展在测试什么

它主要测试三件事：

1. GitHub 里的 library 是否能被转成更自然的观看结构
2. 一次线上展映是否能同时连接作品、方法和活动
3. `MOVA` 是否能成为日历里可持续发布的一条公共线

## 观看提示

你不需要一次把所有入口点完。

更建议的方式是：

- 先看 1 到 2 条你感兴趣的路线
- 如果某个主题更吸引你，再往更深的项目页和知识页走
- 如果你想跟着后续节点继续看，回到 [VIRTURA 官方活动日历](https://lu.ma/VIRTURA) 订阅

## 这类线上展映后续怎么继续长

这场试运行展之后，`MOVA` 还可以继续长成这些形式：

- 单个系列的版本观看室
- 围绕一个概念组织的主题小展
- 某次公开测试或页面上线的开幕页
- 更完整的线上展映与后续活动联动

## 如果这场展映要配一条日历节点

Luma 上更适合用这样的方式发布它：

- 类型：`MOVA online exhibition opening`
- 核心信息：什么时候开放、怎么看、看完继续去哪
- 配套入口：本页 + 一个更深的 GitHub 页面
