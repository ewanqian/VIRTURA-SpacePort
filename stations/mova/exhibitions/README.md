# MOVA 展映索引

这里整理 `MOVA / Museum of Virtual Art` 当前的线上展映、观看室与试运行展。

对 VIRTURA 来说，`MOVA` 不是单纯的“展览概念”，而是一条实际的发布线：把 GitHub 里的作品、研究、archive 和 library 转成更容易观看的公共入口。

## 一页展映至少应该包含什么

后续每个 `MOVA` 展映页，建议至少包含：

- 一个清楚的展览主题
- 一条建议观看路线
- 3 到 8 个真实入口页
- 一段简短的导览文字
- 一个后续活动或订阅入口

这样它才不是“链接堆”，而更像一次真正能走完的线上展映。
