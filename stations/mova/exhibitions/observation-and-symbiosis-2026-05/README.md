# MOVA 展映 02｜《观察与共生》：从扫描、展览到工作坊

> `MOVA` 线上主题小展
> 状态：scheduled

这页是 `MOVA 展映 02` 的展映入口草稿。

它不会把《观察与共生》讲成一个突然完成的单点作品，而是把这条线慢慢摊开来看：它怎么从扫描和地理数据的兴趣长出来，怎么进入展览，怎么又回到分享和工作坊。

## 这场展映想让你看到什么

这次我们更想把一条项目线讲清，而不是只摆一个结果。

对《观察与共生》来说，最值得被看见的不是一句“数据景观”介绍，而是下面这几个层面怎么接到一起：

1. 扫描、地理数据和数字自然为什么会成为这条线的材料来源
2. 它怎么进入展览，而不是只停留在项目说明里
3. 为什么一条展览线后来又值得回到工作坊、分享和公共活动
